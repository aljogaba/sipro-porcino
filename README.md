# SIPRO-Porcino

**Simulador Integral de Producción Porcina**

SIPRO-Porcino es una herramienta técnico-económica para modelar producción, inventarios, alimentación, costos, pie de cría, escenarios y trazabilidad en sistemas porcícolas.

El proyecto forma parte del **Laboratorio de Sistemas Porcícolas**.
