# SIPRO-Porcino

**Simulador Integral de Producción Porcina**

SIPRO-Porcino es una herramienta técnico-económica para modelar inventarios, flujo productivo, consumo de alimento, costos de producción y escenarios operativos en sistemas porcícolas.

El proyecto forma parte del **Laboratorio de Sistemas Porcícolas**, un ecosistema de herramientas técnico-científicas orientadas a la producción, sanidad, análisis de riesgo y toma de decisiones en porcicultura.

## Propósito

El objetivo de SIPRO-Porcino es convertir un modelo productivo-económico validado en campo en una aplicación web profesional, modular y reproducible, útil para análisis técnico, planeación productiva y evaluación de escenarios.

## Alcance inicial

La primera versión funcional se enfocará en el módulo de inventarios y flujo productivo:

- número de vientres;
- parámetros reproductivos;
- nacidos vivos;
- mortalidad por etapa;
- días de lactancia;
- duración de fases productivas;
- inventario estimado por etapa;
- cerdos vendidos;
- flujo anual de producción.

Posteriormente se integrarán módulos de:

- consumo de alimento;
- costos de alimentación;
- medicación y premezclas;
- gastos generales;
- costos de producción;
- análisis de escenarios;
- reportes técnicos.

## Autoría

Modelo desarrollado por Alberto Jorge Galindo-Barboza, con base en experiencia técnica, análisis productivo y validación práctica en sistemas porcícolas.

El proyecto reconoce la contribución conceptual inicial de un colega MVZ, quien proporcionó la primera base de cálculo que posteriormente fue ampliada, refinada y validada a lo largo de los años.

## Nota sobre propiedad intelectual

El archivo Excel fuente del modelo no forma parte del repositorio público.  
La aplicación web se desarrollará a partir de una documentación técnica controlada, validación contra casos de referencia y traducción modular de reglas de cálculo.
